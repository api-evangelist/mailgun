# Mailgun GraphQL

## Description

Mailgun is a REST-only email delivery API platform. No native GraphQL endpoint is publicly offered. This document describes a conceptual GraphQL layer derived from Mailgun's REST API data model, suitable for building a GraphQL facade or for schema reference when integrating Mailgun with GraphQL-native systems.

## Endpoint

Not available. Mailgun does not publish a GraphQL endpoint. The primary REST base URL is:

- US region: `https://api.mailgun.net`
- EU region: `https://api.eu.mailgun.net`

## Schema Source

Conceptual — derived from Mailgun's published REST API reference and official documentation.
